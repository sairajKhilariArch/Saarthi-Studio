One-time router setup

          
    
            
  1. Open your router dashboard (FreeLLMAPI usually runs on http://localhost:3001).
    2. 
            
  2. Add free-tier provider credentials in its Keys / Providers page.
    3. 
            
  3. Enable and order a fallback chain.
    4. 
            
  4. Copy the router's unified API key into the field above, then test the connection.
    5. 
          

          
Free tiers have provider-defined quotas. Fallback only works while another enabled provider has capacity and the router recognises the error as retryable.

        


        

          
Workspace & privacy

          
Studio reads and writes only inside the folder you explicitly open, keeps chats in local SQLite at ~/.local/share/free-ai-studio, and never uploads files anywhere else. Code is sent to your configured router only when you attach it to a message.

          
The editor does not run code, open a terminal, or touch files outside the open folder.
