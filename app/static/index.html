Set up providers once

Add your free-tier provider credentials and configure the fallback chain in FreeLLMAPI. Then create/copy its unified API key into the field above.

  1. Open your router dashboard (usually http://localhost:3001 for FreeLLMAPI).
  2. Add eligible free-tier provider credentials in its Keys / Providers page.
  3. Enable and order a fallback chain if supported.
  4. Copy the router's unified API key here, then test the connection.

Free tiers have provider-defined quotas. Automatic fallback only works when another enabled provider/model has capacity and the router recognizes the error as retryable.
