VS Code extension

Brings the studio into the editor. Runs standalone or against a desktop Studio for the full feature set. Requires VS Code 1.90 or newer.

VSIX

📦Install

Download the .vsix from the Releases page.

Install it:

code --install-extension free-ai-studio-vscode.vsix
Or from the Extensions panel: ⋯ → Install from VSIX…

🖥️Connect a runtime

Full features (threads, agent runs, files, deep search, media) need a running desktop Studio on the same machine — the extension connects to it at http://127.0.0.1:8765.

Without it, the extension falls back to its built-in server with the core chat subset — pointed at your router key in Settings.

The extension mirrors the desktop's agent-run panel: goal, permissions, diff-colored step log, approve/reject, cancel and per-step restore.
