A local AI studio, in Rust.

Saarthi Studio is a local-first AI chat and coding workspace: threads with persistent history, projects, a real file explorer and editor, skills, deep search with cited sources, media attachments, and a live usage dashboard — all served from your machine, on your machine.

Download a release Source on GitHub

Features

Threads & projects

Conversations persist in SQLite under the active project. Switching threads or projects never mixes answers — replies stream in live, no refresh needed.

Media attachments

Attach images, audio or video to a message; stored with the thread and folded into the newest turn for models that accept them.

Deep search

A composer toggle that researches your question with planned web queries or a provider's built-in tools, streaming each step and replying with cited sources.

Projects & files

Open any local folder, browse the tree and edit files in tabs with atomic saves. Workspace access is confined to the folder you open.

Skills

Local SKILL.md packs are discovered, enabled and injected into the chat system prompt; attach one per message or let keyword auto-suggest propose it.

Usage analytics

Every request is logged with latency, tokens and cost signals; the Usage page paginates, sorts and charts them.

How to use

  1. Launch Saarthi Studio — the window and the website are the same UI at http://127.0.0.1:8765.
  2. Open Provider setup and configure the upstream endpoint (FreeLLMAPI by default via Docker, or any OpenAI-compatible preset: Hugging Face, OpenRouter, Groq, Gemini and more). Paste the router's unified API key in Router settings.
  3. Pick or create a project in the top-left selector, then start a thread in the composer.
  4. Chat with a selected model. Attach images/audio/video with the paper-clip control; switch modes (budget/plan) per message; toggle deep search when a question needs sources.
  5. Use the bottom panel terminal for the project's commands, the file explorer to edit, and the Usage page to watch tokens and cost.

Runs headless too: FREE_AI_STUDIO_NO_GUI=1 free-ai-studio serves the website only, and an SSH tunnel keeps it private on your network.

From source on Ubuntu:

./install-and-run.sh

The installer installs prerequisites, builds the Rust app in release mode, starts FreeLLMAPI via Docker Compose, and creates an Applications-menu shortcut. Updating over an existing install keeps all config, history and conversations — they live outside the app folder.
