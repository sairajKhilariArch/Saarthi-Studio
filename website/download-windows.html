Install on Windows

One artifact: a portable x64 zip. No installer, no registry changes — unzip and run.

x64 zip

📂Steps

Download the Windows zip from the Releases page and unzip it (right-click → Extract All).

Run free-ai-studio.exe from the extracted folder.

The modern WebView2 runtime ships with recent Windows 10/11 updates. If the app shows a blank window, install Microsoft Edge WebView2.

SmartScreen: the build is unsigned, so the first launch may warn — choose More info → Run anyway. Updating: replace the folder contents; your config and history live outside it (%APPDATA%\free-ai-studio and local data paths), so an update keeps everything.
