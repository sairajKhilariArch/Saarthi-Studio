Android companion

The phone app is a companion to a running desktop Studio — it connects over HTTPS to the desktop Host API on your own network, not a public cloud. Android 7 (API 24) or newer.

APK

⬇️Install the APK

Download the APK from the Releases page.

In Android settings, allow your file manager or browser to install unknown apps, then open the APK to install.

🔗Pair with your desktop

On the desktop machine, enable the Host API and create a pairing token:

export FREE_AI_STUDIO_HOST_API_ENABLED=true
export FREE_AI_STUDIO_HOST_API_BIND=<LAN IP>
export FREE_AI_STUDIO_HOST_API_TLS_CERT=<cert.pem>   # client-certificate TLS required
export FREE_AI_STUDIO_HOST_API_TLS_KEY=<key.pem>
free-ai-studio host-token create

In the app's connection settings, enter the desktop https://<LAN IP>:8766 URL and the pairing token.

What works over the bridge: streaming chat token-by-token, and the full agent-run tools — the Runs screen with step log, diff previews, approve/reject, cancel and per-step restore. Older desktop hosts degrade gracefully: the app checks host capabilities first. The security model lives in PLATFORM-ARCHITECTURE.md.
