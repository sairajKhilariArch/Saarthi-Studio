Install on Linux

Four ways in: the .deb for Ubuntu-family distros, an AppImage, a portable tarball, or build from source. Requires a 64-bit kernel (amd64).

.debAppImagetar.gzfrom source

📦.deb (recommended on Ubuntu/Debian)

Download saarthi-studio_*_amd64.deb from the Releases page.

Install it:

sudo apt install ./saarthi-studio_*_amd64.deb
# or: sudo dpkg -i saarthi-studio_*_amd64.deb && sudo apt -f install

Launch Saarthi Studio from the app menu, or run free-ai-studio in a terminal.

Upgrades: installing a newer .deb over an older one preserves everything — config, history and conversations live in ~/.config/free-ai-studio and ~/.local/share/free-ai-studio, never in the app folder.

🪄AppImage

Download the AppImage from the Releases page.

Make it executable and run it:

chmod +x saarthi-studio_*.AppImage
./saarthi-studio_*.AppImage

No install step at all — the AppImage is self-contained. Keep it anywhere you like.

📁Portable tar.gz

Download the Linux tar.gz from the Releases page and extract it:

tar -xzf saarthi-studio-linux.tar.gz
cd saarthi-studio-*

Run it in place:

./free-ai-studio

The binary loads its UI from static/ next to itself — keep the extracted folder together.

🛠️From source (Ubuntu)

Clone the repo and run the all-in-one installer:

git clone https://github.com/sairajKhilariArch/Saarthi-Studio.git
cd Saarthi-Studio
./install-and-run.sh

The script installs missing prerequisites, installs the stable Rust toolchain if needed, builds the app in release mode, and starts FreeLLMAPI via Docker Compose. The first build downloads crates from the Cargo registry, so internet is required.

The installer reuses an existing ~/freellmapi and never resets your provider settings, database or history.
