Install on macOS

One universal tarball — the same download runs on Apple silicon and Intel Macs. macOS 12 (Monterey) or newer.

macos-universal tar.gzarm64 + x86_64

📂Steps

Download the macos-universal tar.gz from the Releases page.

Extract and start it:

tar -xzf saarthi-studio-macos-universal.tar.gz
cd saarthi-studio-macos-universal
./free-ai-studio

On the first launch Gatekeeper may stop the unsigned binary — right-click free-ai-studio in Finder and choose Open, then confirm. Terminal launches skip the Gatekeeper prompt entirely.

Why unsigned: no Apple Developer ID is attached to the build yet, and unsigned apps are removed by Gatekeeper when re-opened; the tarball avoids that punishment. Signing and notarization are planned — see the release pipeline for the exact steps that enable them. Updating over an existing install keeps all config, history and conversations: they live outside the app folder.
