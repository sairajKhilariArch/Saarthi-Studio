# Upgrade guide: Saarthi Studio 1.10.0 → 1.11.0

## Before upgrading
1. Open Saarthi Studio 1.10.0 and export **all chats (JSON backup)**. Save the file somewhere outside the app.
2. Confirm the FreeLLMAPI URL/key in Settings and test the connection.
3. If the chat database is valuable, copy the backup to another location. Android's app-private SQLite history is not a substitute for an external backup.

## What changes
- App version: `1.11.0`, version code `13`.
- SQLite database schema: `4 → 5`; migration adds folder, tag, pinned, and favorite columns. It does not recreate or clear the existing conversation/message/preset tables.
- Backup writer emits schema version `3`; importer continues to accept backup schema versions `1`, `2`, and `3`.
- Existing encrypted FreeLLMAPI URL/key and default model are retained. Additional model preference fields default to empty.

## Build and install
Open the project in Android Studio or run the repository GitHub Actions workflow on branch `android`. Use JDK 17, Android Gradle Plugin 8.7.3, Gradle 8.9, Android SDK Platform 35, and Build Tools 35.0.0. A debug build is expected at `app/build/outputs/apk/debug/app-debug.apk`.

Install over the existing app (do not uninstall first), since uninstalling ordinarily removes app-private SQLite history and encrypted settings.

## Acceptance checks after installation
- Open several pre-existing conversations and verify their messages are still present.
- Check prompt presets and run JSON restore from a backup generated by 1.10.0.
- Add a folder/tag, pin and favorite a conversation, restart the app, and verify the values persist.
- Search inside a long message and use Pinned/Favorites/Folder/Tag filters.
- Test stream, Stop, transient failure, Retry and configured fallback models. Never configure a fallback to a model that the router does not expose.
- Use the Free-tier budget tool; if the endpoint is unsupported or returns 401/403, quota is shown as unavailable rather than assumed exhausted.
- Test dictated text and read-aloud/stop speech. Speech behavior depends on installed Android speech services.
- Attach a small JPEG/PNG/WebP/GIF to a vision-capable model. For an unrecognized model, accept the explicit confirmation only when you intend to try vision input.
- Export and re-import a schema v3 backup containing organization metadata; ensure all old content survives.

## Network safety
Keep port 3001 restricted to a trusted local network/hotspot. Do not expose the unified FreeLLMAPI key or server to the public internet. Use HTTPS for remote access.
